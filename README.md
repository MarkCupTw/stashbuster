# Stash Buster（储物克星）

苦力怕不再只追着你跑 —— 它们会主动去搜刮你的仓库：扫描周围**你放置的**储物方块，
挑出物品最多的那个，走过去炸开。

| | |
|---|---|
| **Minecraft** | 1.21.1 |
| **加载器** | NeoForge 21.1.x |
| **运行环境** | 纯服务端（客户端不需要安装） |
| **许可** | MIT |

---

## 特性

- **瞄准储物，不是瞄准人。** 支持箱子、陷阱箱、木桶、潜影盒、漏斗、发射器、投掷器、合成器、
  熔炉/高炉/烟熏炉、酿造台、饰纹陶罐、雕纹书架，以及**其它 mod 的任何标准容器**。末影箱排除。
- **挑物品最多的炸。** 打分公式 `物品数 - 1.5 × 距离`。默认满箱可以压过约 10 格距离差——
  它会绕过近处的空箱子，专程去炸远处装满的那个。
- **只认玩家放置的容器。** 村庄、地牢、遗迹里原有的箱子不受影响，哪怕里面有战利品。
  记录按维度持久化进存档，重启不丢。
- **玩家优先。** 一旦锁定玩家就立刻放弃搜刮。创造与旁观玩家不会被锁定。
- **玩家 24 格内才动手**（旁观模式不计）；中途走出范围，它会放弃。
- **怕猫。** 附近有猫或豹猫时会中断搜刮掉头逃跑——在储物间拴只猫就能防住它。
- **全部可配置。** 见下。

## 安装

1. 给游戏装上 **NeoForge 1.21.1**
2. 把 `stashbuster-1.0.0.jar` 放进 `.minecraft/mods/`
3. 启动游戏。首次启动会生成配置文件 `config/stashbuster-common.toml`

单机不需要任何额外设置。纯服务端模组，不含渲染 / UI / 网络包。
---

## 配置

生成于 `config/stashbuster-common.toml`。

### `[general]`

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关。关掉后苦力怕恢复原版行为，已记录的数据仍保留 |
| `searchRadius` | `24` | 储物方块搜索半径（格）。未加载区块里的方块读不到，会被跳过 |
| `requireNearbyPlayer` | `true` | 是否要求半径内有玩家才激活。**只排除旁观模式**：生存 / 创造 / 冒险都算 |
| `scoreUpdateIntervalTicks` | `20` | 重新挑选目标的最小间隔（tick），避免每 tick 重算 |
| `minimumItemCount` | `1` | 物品少于该值不作为目标。设 `0` 则空容器也炸 |

`requireNearbyPlayer` 只把**旁观模式**排除在外——生存、创造、冒险模式都算，
所以创造模式下建基地时苦力怕照样会来，纯旁观观察时不会。
判定半径与 `searchRadius` 共用（默认 24 格）。
### `[targets]`

| 键 | 默认 | 说明 |
|---|---|---|
| `excludedBlocks` | `["minecraft:ender_chest"]` | 不参与搜刮的方块 ID 列表，可增删 |

### `[scoring]`

| 键 | 默认 | 说明 |
|---|---|---|
| `distancePenalty` | `1.5` | 每 1 格距离扣多少分 |
| `countMode` | `TOTAL_ITEMS` | `TOTAL_ITEMS` = 堆叠数量总和；`OCCUPIED_SLOTS` = 非空格子数 |

```
score = 物品数 - distancePenalty × 距离
```

把 `distancePenalty` 调大更执着于就近目标，调小更执着于物品多
（调到 `0` 就完全只看物品数量、无视距离）。

## 哪些方块算目标

判定标准是**方块实体是否实现 `Container` 接口**，自动覆盖：

- 箱子、陷阱箱、木桶、潜影盒（17 色）
- 漏斗、发射器、投掷器、合成器（Crafter）
- 熔炉、高炉、烟熏炉、酿造台
- 饰纹陶罐、雕纹书架、唱片机（后两者也算 `Container`，只是可容纳 1~6 件）

以及**其它 mod 的标准容器**——只要它的方块实体按规范实现 `Container`，无需本模组适配。

**末影箱不参与**：它默认列在 `excludedBlocks` 里。`EnderChestBlockEntity` 本身并未实现
`Container`（它的内容属于玩家个人的末影储物，并不存在于世界里），所以本来就不会被选中；
列出来是为了显式表达意图，并在将来原版改动时提供保护。

想让某类方块免于被盯上（例如唱片机），往 `excludedBlocks` 里加 ID 即可：

```toml
excludedBlocks = ["minecraft:ender_chest", "minecraft:jukebox"]
```

## 行为细节

### 只认装模组之后玩家新放的方块
通过 `BlockEvent.EntityPlaceEvent` 记录玩家放置的坐标，写进存档（按维度分别持久化）。
村庄、地牢、遗迹里原有的容器不参与；玩家自己拆掉时同步移除记录；
坐标失效的条目会在下次搜索时顺手清理。

### 双重箱子
两个半块共享一个大箱子，按**一份**计分（不会分数翻倍），寻路只认一个坐标。
如果爆炸只炸到一半，只有被炸的那一半的物品会掉出，另一半保留自己的东西。

### 激活条件
苦力怕只有在自己 **24 格**（`searchRadius`）内有玩家时才主动搜刮，旁观模式不算。
这个条件是**持续检查的，不只在出发那一刻检查**：玩家走远到 25 格以外，它会放弃并停下。

### 玩家优先
苦力怕一旦锁定了玩家，就立刻放弃搜刮去找玩家，容器只是没锁定玩家时的备选目标。

### 怕猫
附近有猫或豹猫时会释放移动权，让原版苦力怕的躲猫行为接管。判定条件近似原版
`AvoidEntityGoal`：水平 6 格 / 垂直 3 格内、且有视线。检查结果有缓存，不会每 tick 扫实体。

### 性能
不做世界范围扫描：只遍历"玩家放置过容器的坐标集合"，先做纯算术的距离淘汰，
再看区块是否加载，最后才读容器内容。每个苦力怕有搜索冷却与寻路重算间隔，
目标长期不可达时会放弃、临时拉黑并进入冷却。
